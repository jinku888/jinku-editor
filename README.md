# Jinku Editor｜互动短片编辑器

用可视化编辑器创作分支剧情，组合画面、对白与互动选择，并预览观众看到的作品。

> 编辑器源码暂未公开。本仓库用于展示产品、精选作品和收集反馈。

## 体验互动短片

精选案例正在准备公开体验链接。链接通过未登录访问验证后，会更新在这里。

## 能做什么

- 编排互动剧情和分支选择
- 管理画面、视频及其他作品素材
- 预览作品的播放与选择流程
- 发布互动短片供观众体验

## 反馈与交流

如果你遇到播放问题，或希望编辑器支持某项功能，请在 [Issues](https://github.com/jinku888/jinku-editor/issues) 留言，并附上使用设备、浏览器及复现步骤。
